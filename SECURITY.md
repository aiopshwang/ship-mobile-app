# Security

## Reporting

Report suspected vulnerabilities through this repository's GitHub private
vulnerability-reporting flow. Do not include live credentials, private user data,
or an exploit against systems you do not own or lack permission to test.

## Scope

This repository currently contains instruction files only. Review the skill before
installation, and treat any future scripts, dependencies, or network integrations
as a separate security boundary.

The skill does not grant an agent permission to deploy, upload, submit, publish,
migrate production data, change external account settings, or disclose secrets.
Those actions still require the user's authorized scope and the host's controls.
