# Privacy

Ship Mobile App is an instruction-only Agent Skill. The maintainer operates no
runtime service, analytics endpoint, cookie, or telemetry collector for this
repository.

When the skill is used, the host agent may inspect files, run tools, or access
services within the user's authorized task. Data handling by that host, model,
installer, package registry, source host, or connected tool is governed by the
respective provider's settings and policies, not by this repository.

The published skill must not contain raw source conversations, private project
code, user records, credentials, local absolute paths, private corpus metadata, or
internal operational identifiers. Its examples are synthetic and generalized.

If a future version adds maintainer-operated telemetry or a network service, this
policy and the product behavior must be updated before that collection begins.
